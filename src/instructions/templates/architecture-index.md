# Template — `docs/reference/arquitetura/INDEX.md` (router index)

> Source: round R13 scope (issue #46) — J12 STAGE 5.1 · Module version: 1 — 2026-08-11
> Anti-drift: the INDEX is a ROUTER — its job is to make the agent load each doc only when relevant. One line per architecture document, "Quando ler" always filled. An existing INDEX.md is preserved (never edited, never overwritten): coverage gaps go to the closing gap analysis.
> Payload in the target project's docs language (PT-BR by default).

```markdown
# Índice de arquitetura — {NOME_DO_PROJETO}

> Criado em: {DATA} · Última revisão: {DATA}
> Regra: doc desatualizado é corrigido ou marcado como obsoleto — nunca deixado apodrecendo em silêncio.

| Documento | Conteúdo | Quando ler |
|---|---|---|
| `arquitetura.md` | Arquitetura interna do sistema | Antes de alterar regras de negócio ou a estrutura de módulos |
| {doc gerado nas STAGEs 3–4 — ex.: `integracoes.md`} | {o que cobre} | {ex.: "Antes de mexer em integrações"} |
| `runbooks/deploy.md` | Como publicar uma versão | Antes de qualquer deploy |
| `runbooks/rollback.md` | Como reverter uma versão | Quando um deploy falha ou introduz regressão |
| `runbooks/incidentes.md` | Resposta a incidentes em produção | Durante um incidente |
| `../decisions/` | ADRs — registros de decisão técnica | Antes de mudar uma decisão técnica |

## Regra de cabeçalho dos documentos

Todo documento de arquitetura carrega no topo: data de criação, campo
"última revisão" e a regra de obsolescência acima.
```

**Usage rules:**

- The table covers EVERY document under `arquitetura/`, including the ones
  generated by the reference bootstrap (J12 STAGEs 3–4) and the runbooks,
  plus the reference to `decisions/`.
- "Quando ler" is written as a trigger situation ("Antes de…", "Durante…"),
  never as a summary — the summary belongs to the "Conteúdo" column.
- Docs not yet written (greenfield) are listed with `<!-- TODO: preencher -->`
  in "Conteúdo" — the INDEX is born complete as a map, even when the
  destinations are placeholders.
